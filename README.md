# Blackjack C#

This is a basic console app implementation of the classic game of Blackjack using C#

## Features

- Play as a player against the CPU dealer
- Rules of Blackjack:
  - The goal is to get as close to 21 as possible without going over.
  - Face cards (King, Queen, Jack) are worth 10 points, Aces can be 1 or 11.
  - The dealer must draw until their hand is 17 or higher.
- Type `debug` during the game to view the dealer's hand (cheat)
